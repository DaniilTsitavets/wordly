# Daily Game — Mock

Mock-реализация дейли-игры: идиома + 4 варианта ответа на русском.

Каждый день автоматически назначается одна случайная игра из пула незанятых. В моке день определяется по CET-времени (смена в 23:00 CET), но для тестирования можно просто читать — мок назначит игру при первом обращении и будет возвращать её весь "день".

Данные живут в памяти. После перезапуска сервера назначения сбрасываются.

---

## Публичный эндпоинт

```
GET /daily-game
Header: Authorization: Bearer <token>
```

### Ответ

```json
{
  "id": 1,
  "idiom": "Break a leg",
  "options": [
    "Сломать ногу",
    "Пожелать удачи",
    "Убежать",
    "Упасть"
  ],
  "correct_option": 2
}
```

`correct_option` — индекс правильного варианта (1–4).

### Поведение мока

- Если на сегодня уже назначена игра — возвращает её.
- Если нет — выбирает случайную из незанятых (`scheduled_date: null`) и назначает на сегодня.
- Если все игры уже заняты → `404 NOT_FOUND`.

### Коды ошибок

| Статус | Код | Когда |
|--------|-----|-------|
| 404 | `NOT_FOUND` | Нет доступных игр в пуле |

## Начальные тестовые данные

| id | Идиома | Правильный вариант | Назначена |
|----|--------|-------------------|-----------|
| 1  | Break a leg | 2 — «Пожелать удачи» | — |
| 2  | Hit the sack | 3 — «Лечь спать» | — |

## Управление через Admin API

Полный CRUD на `/admin/daily-games`. Подробнее: [ADMIN.md](./ADMIN.md#дейли-игры-admindaily-games).

### Добавить игру в пул

```
POST /admin/daily-games
{
  "idiom": "Spill the beans",
  "option_1": "Приготовить еду",
  "option_2": "Рассекретить информацию",
  "option_3": "Уронить урожай",
  "option_4": "Переехать в деревню",
  "correct_option": 2
}
→ 201 { "id": 4, "scheduled_date": null, ... }
```

### Посмотреть все игры (включая назначенные)

```
GET /admin/daily-games
→ [
    { "id": 1, "idiom": "Break a leg", ..., "scheduled_date": "2026-05-23" },
    { "id": 2, "idiom": "Hit the sack", ..., "scheduled_date": null },
    { "id": 3, "idiom": "Bite the bullet", ..., "scheduled_date": null }
  ]
```

`scheduled_date: null` — игра ещё не была назначена и войдёт в ротацию.

## Отличия от реального бэкенда

| | Мок | Реальный бэкенд |
|--|-----|-----------------|
| Смена дня | При первом запросе нового дня | В 23:00 CET (lazily при первом запросе) |
| Timezone | Системное время сервера | Europe/Paris (CET/CEST) |
| Конкурентность | Не защищена | `SELECT FOR UPDATE` + unique constraint |
