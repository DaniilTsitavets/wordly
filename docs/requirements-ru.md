# Wordly. Бизнес-требования к функциональности изучения слов по языковым темам

**Аудитория документа:** Product · Design · Development

---

## 1. Цель документа

Документ описывает бизнес-требования к функциональности изучения иностранных слов через тематические уровни. Продукт помогает пользователям систематически запоминать слова с помощью мнемотехник, различных механик обучения, интервальных повторений и игровых элементов.

---

## 2. Предметная область

### 2.1 Что делает продукт

**Wordly** — 
веб-приложение для изучения иностранных слов. Продукт построен вокруг двух методически обоснованных техник усвоения лексики:

1. **Мнемоники (аудио и визуальные ассоциации)** — ускоряют первичное кодирование слова в памяти за счёт яркого образа, связанного со звучанием.
2. **Интервальные повторения (spaced repetition)** — возвращают слово на повторение в моменты, рассчитанные по кривой забывания, чтобы не дать ему «выпасть» из памяти.

Wordly систематизирует и автоматизирует применение этих техник: контент структурирован по темам и подтемам, каждое слово проходит через последовательность обучающих механик возрастающей сложности (мнемоника → карточки → сопоставление → восстановление пропусков → сборка слова), а после освоения автоматически попадает в очередь повторений с интервалами 1 / 3 / 7 / 14 / 21 / 30 дней.

Ключевые функциональные блоки:

- **Структурированный контент** — иерархия «Тема → Подтема → Уровни обучения».
- **5 обучающих механик** разной когнитивной сложности — от пассивного ознакомления до активного воспроизведения.
- **Мнемоники** — образные ассоциации как инструмент быстрого запоминания.
- **Интервальное повторение** с фиксированными интервалами (1, 3, 7, 14, 21, 30 дней), выстроенными в соответствии с кривой забывания.
- **Геймификация** — gems (внутренняя валюта), streak, дневные цели, игра дня; тамагочи (in the future) — для поддержки регулярности занятий.
- **Персональный словарь** — список изученных слов с метаданными прогресса.
- **Статистика и метрики** прогресса (всего слов, streak, % «помню», очки).

### 2.2 Какую проблему решает

Ключевая трудность при изучении иностранного языка — **кривая забывания (Ebbinghaus forgetting curve)**: без своевременного повторения большая часть новой лексики уходит из памяти уже в первые сутки после знакомства со словом, и через несколько дней пользователь не может воспроизвести почти ничего из выученного. При этом методически правильные техники запоминания — мнемоники (ускоряют кодирование) и интервальные повторения (противостоят кривой забывания) — известны и доказали эффективность, но требуют системного применения, которое сложно поддерживать самостоятельно.

**Wordly решает эту проблему**, выстраивая обе техники в единый управляемый процесс:

1. **Мнемоники как этап первичного знакомства** — слово запоминается через образную ассоциацию, а не зубрёжкой, поэтому быстрее «зацепляется» в памяти.
2. **Многоступенчатые механики обучения** — слово прорабатывается с нескольких сторон (узнавание → сопоставление c переводом → частичное написание  → польное написание), что укрепляет связь и переводит её в долговременную память.
3. **Интервальные повторения по расписанию** — система сама возвращает слово на повторение именно тогда, когда оно вот-вот должно «выпасть» из памяти по кривой забывания, а пользователю не нужно вручную планировать график повторений.
4. **Геймификация** — поддерживает регулярность занятий, без которой ни мнемоники, ни spaced repetition не работают.

## 3. Целевая аудитория

### 3.1 Первичная аудитория

- **Студенты и школьники**, изучающие иностранные языки в рамках учебной программы или для подготовки к экзаменам.
- **Самоучки 18–35 лет**, которые учат язык для работы, переезда или путешествий с нуля.
- **Пользователи, испытывающие трудности с запоминанием слов** — те, кому традиционные методы (например, списки) не подходят.

### 3.2 Вторичная аудитория

- Люди, изучающие второй/третий язык.
- Преподаватели языков, ищущие дополнительные инструменты для своих учеников.
- Пользователи языковых приложений (например, Duolingo), недовольные эффективностью запоминания именно лексики.

### 3.3 Потребности пользователей

| Потребность | Как продукт её закрывает |
| --- | --- |
| Быстро и устойчиво запоминать новые слова | Мнемоники + 5 механик от пассивной к активной |
| Не забывать выученное со временем | Интервальные повторения (1/3/7/14/21/30 дней) и секция Recall |
| Сохранять мотивацию к ежедневным занятиям | Streak, gems, дневные цели; тамагочи и игра дня (in the future) |
| Видеть собственный прогресс | Статистика (Stats), словарь (Vocabulary), счётчик изученных слов |
| Попробовать продукт без регистрации | Guest-режим: доступ к первой подтеме без аккаунта |
| Учиться в удобном темпе | Персональная дневная цель в минутах, настраиваемая в профиле |
| Удобный визуальный опыт | Цветовая тема приложения, выбираемая в профиле |

Ниже описаны ключевые сущности и их бизнес-смысл. Техническая реализация — вне скоупа.

| Сущность | Бизнес-смысл |
| --- | --- |
| **users** | Зарегистрированный пользователь. Хранит имя, фамилию, email, язык интерфейса, настройки уведомлений, дневную цель в минутах, текущий стрик и количество гемов (внутренняя валюта). |

## 7. Пользовательские сценарии

### 7.1 Первый запуск приложения

```
Открыть приложение
  → Экран загрузки
  → Кнопка «Начать учить» ("Start learning")
  → Пользователь зарегистрирован?
        НЕТ → Popup регистрации
               → Экран выбора дневной цели (минуты в день)
               → Главный экран
        ДА  → Popup авторизации
               → Главный экран
```

### 7.2 Навигация по темам и подтемам

```
Главный экран
  → Отображается тема
  → Список доступных для прохождения подтем
  → Список всех слов темы
  → Кнопка «Начать учить» ("Start learning")
  → Экран подтемы (список уровней)
  → Кнопка «Начать» ("Start")
  → Level 0 (если есть мнемоники) или Level 1
```

### 7.3 Прохождение подтемы (основной флоу)

```
Начать изучение подтемы
  → Есть мнемоники?
        ДА  → Level 0 (мнемоники) → Экран окончания уровня
        НЕТ → Level 1
  → Level 1 → Popup Окончания lvl → Экран подтемы
  → Level 2 → Popup Окончания lvl → Экран подтемы
  → Level 3 → Popup Окончания lvl → Экран подтемы
  → Level 4 → Popup Окончания подтемы
  → Все подтемы пройдены?
        НЕТ → Переход к следующей подтеме
        ДА  → Переход к следующей теме
  → Все темы пройдены?
        НЕТ → Переход к следующей теме
        ДА  → Экран окончания обучения
```

### 7.4 Повторение слов

```
Главный экран / Экран повторения
  → Список слов, у которых сегодня наступил интервал
  → Кнопка «Повторить» ("Recall")
  → Механика — напечатать слова из букв
  → Система фиксирует результат и планирует следующий интервал
  → Popup Окончания Recall
```

## 8. Структура обучения

### 8.1 Иерархия контента

```
Topic (Тема)
└── Subtopic (Подтема)
        ├── Level 0 — Мнемоники           [только если есть мнемоники]
        ├── Level 1 — Flashcards (Карточки)
        ├── Level 2 — Matching (Сопоставление с переводом)
        ├── Level 3 — Filling Gaps (Заполнение пропусков)
        └── Level 4 — Word Builder (Сборка слова)
```

### 8.2 Список слов перед стартом (**In the future:**)

- При открытии темы пользователь может увидеть все слова, которые будет изучать.
- Список отображается до начала обучения.
- Пользователь сможет отметить знакомые слова и исключить их.

### 8.3 Логика прогресса по словам

- Слова нулевого уровня (с мнемониками) в уровнях 1–4 проходятся наравне с остальными.
- Мнемоника не показывается повторно в уровнях 1–4.

## 9. Нулевой уровень: Мнемоники

### 9.1 Условие появления

Нулевой уровень отображается только если в подтеме есть хотя бы одно слово с мнемоникой.

### 9.2 Экран и формат карточки

**Элементы экрана:** карточка, кнопки Previous / Complete, прогресс-бар.

**Лицевая сторона:**

- Мнемо-изображение (визуальная ассоциация).
- Изучаемое слово (на иностранном языке).
- Транскрипция.
- Текст, начинающийся с фразы «Представьте...» — образная история ассоциации.
- Кнопка воспроизведения произношения слова (и/или автовоспроизведение).

**Обратная сторона:**

- Перевод слова на родной язык пользователя (крупно).
- Слово (мелко).
- Пример употребления в контексте.

### 9.3 Навигация

- Клик по карточке — переворот.
- Пользователь перемещается по карточкам вперёд и назад.
- Список карточек не отображается — только текущая карточка.
- Уровень завершён, когда пользователь просмотрел все карточки хотя бы по одному разу и нажал на кнопку «Завершить» ("Complete").

### 9.4 Связь с дальнейшим обучением

Все слова нулевого уровня автоматически включаются в уровни 1–4 той же подтемы.

## 10. Механики обучения

### 10.1 Flashcards (Карточки) — Level 1

**Цель:** первичное знакомство со словом и его звучанием.

**Бизнес-логика:** пассивное ознакомление со словом.

**Элементы экрана:** карточка, кнопки Next / Previous, прогресс-бар.

- Front: изображение, слово, транскрипция, подсказка переворота, кнопка Next.
- Back: перевод (крупно), слово (мелко), пример в контексте с переводом, кнопка Next.

**Поведение:**

- Карточка показывает иностранное слово + произношение.
- Клик по карточке — переворот; пользователь видит перевод слова на родной язык + пример употребления.
- Пользователь листает все слова подтемы вперёд/назад.
- Оценки нет — все просмотренные слова фиксируются.
- Уровень завершён, когда пользователь просмотрел все карточки хотя бы по одному разу и нажал на кнопку «Завершить» ("Complete").

### 10.2 Matching (Сопоставление) — Level 2

**Цель:** закрепление пары «слово ↔ перевод».

**Бизнес-логика:** установление связи «слово → перевод».

**Элементы экрана:**

- Две колонки: иностранные слова и переводы.
- Индикатор прогресса, прогресс-бар.

**Поведение:**

- Показывается набор иностранных слов и переводов.
- Пользователь выбирает пару из двух колонок.
- Верная пара — зелёная, фиксируется.
- Неверная пара — красная, можно повторить.
- При наличии неверно сопоставленных пар пользователь не пропускается дальше, пока все пары не будут соединены верно.
- Уровень завершён, когда все пары сопоставлены верно.

### 10.3 Filling Gaps (Заполнение пропусков) — Level 3

**Цель:** закрепление правописания через восстановление пропусков.

**Бизнес-логика:** активное воспроизведение корректного написания слова по памяти.

**Элементы экрана:**

- Слово с пропущенными буквами.
- Подсказка (возможность прослушать аудио произношение).
- Поле ввода.
- Кнопки Reset / Check Answer.
- Прогресс-бар.

**Поведение:**

- Пользователь вводит недостающие буквы.
- Correct → зелёный, переход к следующему слову.
- Wrong → красный, повтор попытки.

### 10.4 Word Builder (Сборка слова) — Level 4

**Цель:** закрепление правописания.

**Бизнес-логика:** закрепление написания слова — наиболее сложный этап.

**Элементы экрана:**

- Подсказка: перевод и/или изображение (изображение предпочтительнее).
- Кнопка воспроизведения произношения слова (TTS).
- Поле ответа.
- Набор букв.
- Кнопки Reset / Check Answer.
- Прогресс-бар.

**Поведение:**

- Нажатие букв формирует слово в поле ответа.
- Клик «Check answer» («Проверить ответ») — проверка.
- Correct → зелёный, переход к следующему слову.
- Wrong → красный + «Try again», повтор попытки.

### 10.5 Recall

**MVP:** механика Word Builder.

**Общая логика:**

- После завершения подтемы слова попадают в очередь повторения с интервалами (см. таблицу).
- Каждый день система формирует список слов с наступившим интервалом — можно посмотреть в секции Recall (закреплена в header — иконка «Мозг»).
- Кнопка «Recall» («Повторить»).
- **MVP — механика Word Builder:**
  - Показывается перевод.
  - Пользователь составляет иностранное слово из предложенных букв + клик по кнопке «Check answer» («Проверить ответ»).
  - При ошибке — показывать «Try again» и предложить ещё раз ввести слово.

**In the future:**

- Система засекает время выполнения каждого слова.
- Фиксируется время ввода.
- Лучший результат по времени (личный рекорд) сохраняется.
- % слов, вспомненных на каждом интервале. Отображается в разделе Stats профиля.
- Контекстный режим: показывается предложение с пропуском на иностранном языке и слово на исходном языке — пользователь вводит перевод слова на иностранный язык целиком.

**Интервалы:**

| Шаг | Интервал |
| --- | --- |
| 1 | +1 день |
| 2 | +3 дня |
| 3 | +7 дней |
| 4 | +14 дней |
| 5 | +21 день |
| 6 | +30 дней |

**Цель:** активное воспроизведение слова без подсказок.

### 10.6 Аудио произношение

- Озвучка доступна во всех механиках обучения, кроме Matching: Level 0 (мнемоники), Flashcards (Level 1), Filling Gaps (Level 3), Word Builder (Level 4) и Recall.
- Произношение воспроизводится через TTS.

## 15. AI Chat (AI-ассистент)

### 15.1 Назначение

Разговорный AI-тренер для практики выученной лексики в живом диалоге на изучаемом языке. AI-ассистент не объясняет грамматику и не работает как «классная комната» — он включает пользователя в реалистичную ролевую ситуацию вокруг подтемы и создаёт естественные поводы использовать целевые слова.

### 15.2 Доступ и контекст

- Сессия привязана к конкретной подтеме: целевой список слов — слова этой подтемы.
- Доступ — только для авторизованных пользователей.

### 15.3 Открывающая фаза

- Ассистент придумывает уникальный реальный сценарий, естественно подходящий подтеме (например, «Еда» → фермерский рынок; «Кухня» → кулинарный мастер-класс).
- Берёт на себя роль персонажа в этом сценарии и приглашает пользователя включиться в разговор.
- Не представляется как AI или тренер.
- Открывающее сообщение — не более 3–4 предложений.

### 15.4 Правила беседы

- Длина каждого ответа ассистента — 2–4 предложения.
- Язык диалога — только изучаемый. Если пользователь пишет на родном языке или нечитаемо, ассистент остаётся в роли и просит повторить на изучаемом языке.
- Ассистент внутренне отслеживает, какие из целевых слов пользователь использовал в естественном контексте, но не сообщает об этом во время диалога.
- Подталкивает к целевым словам ситуативно (через вопросы и описания), без прямого требования.
- Корректирующая обратная связь — только неявная (implicit recast): корректная форма вплетается в ответ ассистента, без формулировок «правильно так» / «надо сказать». Орфографические ошибки тихо запоминаются и попадают в финальную сводку.
- Off-topic запросы (программирование, политика, общие знания) отклоняются в роли, без выхода из сценария.
- На запрос подсказки — одна подсказка в роли (через описание или вопрос), но без перевода целевого слова.

### 15.5 Завершение сессии и сводка

- Пользователь завершает сессию ключевыми словами: «stop», «finish», «done», «end», «quit», «конец», «стоп», «хватит» и близкими по смыслу.
- Ассистент выходит из роли и открывает сводку фиксированной фразой «Great practice! Here's how your session went».
